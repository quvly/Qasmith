# Qasmith for Visual Studio Code

Edit `.smith` programs with highlighting, snippets, live diagnostics, completion, hover, signature help, navigation and an outline. In a trusted workspace, use the **Qasmith** commands to check, compile, simulate, optimize, or preview OpenQASM.

Install Qasmith CLI 0.9.0 separately. Put the executable on PATH or set `qasmith.executablePath` to its absolute path in User Settings. Use **Qasmith: Restart Language Server** to retry after installing it. All editor analysis runs locally.

[Setup and programming guide](https://github.com/quvly/Qasmith/blob/main/docs/tooling/vscode.md)
