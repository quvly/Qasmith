## Verification results

- `gofmt -w .`, `go test ./...`, `go vet ./...`, and `go build ./cmd/qasmith` completed successfully.
- `go run ./examples/optimization/qubo` returned the optimal assignment `[1 0 0]` with energy `-1.75` after JSON round-trips.
- Independent OpenQASM syntax checks ran using the existing integration harness, and a separate byte comparison matched the circuit builder to its golden output.

## Limits and compatibility

The solver defaults to 20 variables, with a configurable ceiling of 24. Models require a positive variable count, including constant-only objectives. Version 1 JSON uses a dense vector for single-variable coefficients. Float64 evaluation can report intermediate overflow and can lose precision from coefficient rounding or cancellation. The original compiler and extension APIs remain in use, and optimization bindings are planned for a future phase.
