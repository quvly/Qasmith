## Verification

`gofmt -w .`, `go test ./...`, `go vet ./...`, and `go build ./cmd/qasmith` completed successfully. The OpenQASM syntax check used Python 3.12 with the OpenQASM reference parser 1.0.1. The seeded circuit-builder run produced every four-bit outcome over 4,096 shots, with individual counts from 219 to 282.

## Compatibility and limits

Smith declarations or bindings that used newly reserved control-flow or Boolean keywords need renaming. Previously registered host names that became keywords remain importable with an explicit alias. Existing functions named `len` or `qreg` retain their resolution precedence. In Go, use keyed `extension.Value` and `qasmith.Compiler` literals because those structs gained fields.

Host-dependent static values are deferred by `check` and evaluated during compilation or evaluation. Arrays have a nonempty fixed shape. The language supports increasing ranges, and measurement remains a terminal return at the top level of the quantum entry function.
