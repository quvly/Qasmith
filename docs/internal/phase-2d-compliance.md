## Verification

`gofmt -w .`, `go test ./...`, `go vet ./...`, and `go build ./cmd/qasmith` passed. The full test run enabled the existing independent OpenQASM parser through Python 3.12.

With the example's fixed seed and 200 objective evaluations, the exact expectation moved from 0.93581813 to −0.02043538. The search stopped at its evaluation budget. The best sampled bitstring was `101`, with energy −0.25. The exhaustive reference independently found −0.25, and 703 of the 1,000 final shots had that energy.

## Limits and compatibility

QAOA is a heuristic. The local simulator supports 16 qubits, while larger circuits can be exported within the compiler's circuit budgets. The initial search uses the X mixer and bounded coordinate polling. Configurable evaluators and optimizers can replace search components, and the hybrid helper still samples locally for the final run. The CLI takes QUBO JSON, and direct Ising input is available in Go. Existing compiler and host interfaces require no migration.
