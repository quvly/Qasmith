## Verification

`gofmt -w .`, `go test ./...`, `go vet ./...`, and `go build ./cmd/qasmith` passed. The full test run used the independent OpenQASM reference parser. A separate comparison found byte-identical optimized QASM from the Smith and TSP JSON workflows at the same settings.

The original Phase 3A regression still verifies all 512 assignments, six feasible tours, and a classical minimum of 80. With seed 42 and 1,000 shots, the source parameters gave 34 feasible samples and 15 optimal samples. The exact-objective search with 200 evaluations and three additional starts reduced expected energy from 1801.72967931 to 1240.46780612. It stopped at the evaluation budget. The separate final run gave 110 feasible and 46 optimal samples.

## Limitations and migration

A terminal producer owns the entire measured circuit. Local simulation remains limited to 16 qubits, while larger circuits can be exported within compiler budgets. Host value validation occurs during compilation and trusted Go callbacks must honor the supplied work limits. The root Bell example is now [bell.smith](../bell.smith), and the root [program.smith](../program.smith) demonstrates optimization. Use keyed literals for expanded public structs as described in the [extension guide](optimization/host-optimization-extensions.md).
